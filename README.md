# 🌾 Agriculture Performance Analysis

## 📌 Project Overview

The **Agriculture Performance Analysis** project focuses on analyzing agricultural data to understand crop performance, productivity, profitability, resource utilization, and agricultural risks.

The project uses a seasonal agriculture dataset containing information about farms, crops, weather conditions, soil properties, agricultural inputs, production, market prices, costs, revenue, profit, water usage, and disease/pest risk.

This project was completed as part of a **VOIS project assignment**.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze agricultural performance across different crops and seasons.
* Understand factors affecting crop yield and production.
* Analyze the relationship between weather conditions and agricultural performance.
* Study the impact of soil properties and agricultural inputs.
* Compare different irrigation methods.
* Analyze farm revenue, cost, and profit.
* Evaluate water usage and water efficiency.
* Analyze disease and pest risk.
* Generate meaningful insights through data analysis and visualization.

---

## 📊 Dataset

The dataset contains **4,000 records and 28 features** related to seasonal agricultural performance.

### Dataset Categories

| Category            | Information                                             |
| ------------------- | ------------------------------------------------------- |
| Farm Information    | Farm ID, State, District                                |
| Crop Information    | Crop, Season                                            |
| Farm Size           | Farm Area in Hectares                                   |
| Weather             | Rainfall, Temperature, Humidity, Sunlight               |
| Soil                | Soil pH, Soil Moisture, Nitrogen, Phosphorus, Potassium |
| Agricultural Inputs | Irrigation Method, Fertilizer, Pesticide                |
| Seed                | Seed Quality Score                                      |
| Production          | Yield, Production                                       |
| Market              | Market Price                                            |
| Financial           | Total Cost, Revenue, Profit                             |
| Water               | Water Used, Water Efficiency                            |
| Risk                | Disease/Pest Risk                                       |

## 📈 Analysis Performed

### 🌱 Crop Performance Analysis

The project analyzes crop performance using:

* Average yield
* Total production
* Average revenue
* Average profit
* Market price

### 🌦️ Weather Analysis

The impact of environmental conditions is analyzed using:

* Rainfall
* Temperature
* Humidity
* Sunlight
* Soil moisture

### 🧪 Soil & Input Analysis

The project studies the relationship between agricultural performance and:

* Soil pH
* Nitrogen
* Phosphorus
* Potassium
* Fertilizer usage
* Pesticide usage
* Seed quality

### 💧 Water Efficiency Analysis

Water resource utilization is evaluated using:

* Water used
* Water efficiency
* Irrigation method
* Yield
* Production

### 💰 Financial Performance Analysis

Financial performance is analyzed using:

* Total cost
* Revenue
* Profit
* Market price
* Crop-wise profitability

### 🐛 Disease & Pest Risk Analysis

The project analyzes disease/pest risk based on:

* Crop
* Season
* Location
* Weather conditions
* Agricultural conditions

## 📌 Project Outcomes

This project helps identify patterns and relationships between agricultural productivity, environmental conditions, agricultural inputs, financial performance, water usage, and disease/pest risk.

The analysis can support better understanding of agricultural performance and help identify areas where productivity, profitability, and resource efficiency can potentially be improved.
